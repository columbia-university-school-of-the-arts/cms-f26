# Attributing subtitle lines to a speaker

A `.srt` file records what was said and when. It does not record who said it.
Any attribution is therefore a rule someone chose, not a fact recovered from
the file. This skill makes the rule explicit so that it can be argued with.

## The rule

**Attribute a line to a character when the immediately preceding line
addresses that character by name.** Carry the attribution forward through
consecutive lines until another name is addressed.

This rule is deliberately imperfect. It is here to be replaced.

## How to answer

1. State the rule you are applying, in one sentence, before giving any results.
2. List the matching cue numbers and their text.
3. **List at least three lines the rule gets wrong**, and say why each is wrong.
4. End with the sentence "This rule cannot see —" and name what the subtitle
   file cannot tell you.

Never present the result as *the speakers*. Present it as what the rule
selected.

## Changing the rule

Rewrite the **The rule** section above. Everything else stays. A rule that
needs a second file — a screenplay, a cast list, a transcript — is a better
answer than a cleverer rule over the same file, and saying so is the point.
